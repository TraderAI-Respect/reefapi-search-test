# Отдельный парсер Mac mini через VISI API

Ручной workflow: **VISI API - Mac mini M1-M5** (`.github/workflows/visi-mac-mini.yml`). Существующие ASIC-парсеры не изменяются.

## Перед запуском

- Нужен действующий **API-тариф VISI** и уже настроенный секрет репозитория `VISI_API_KEY`. Тариф «Старт» для приложения/Telegram не подходит. Код ничего не покупает и не меняет тариф.
- Убедиться, что в дневной квоте достаточно пяти вызовов и другой парсер сейчас не расходует её. API-шлюз входит в API-тариф без доплаты: согласно официальной документации, общий лимит до 1500 запросов search/item в UTC-сутки, 6 поисковых запросов в минуту. Актуальная квота ответа проверяется во время работы.
- В GitHub Actions вручную выбрать **Run workflow**, подтвердить `api_plan_confirmed`. Значение по умолчанию — false. Подтверждение относится к конкретному запуску, не включает расписание или автоповтор.

## Объём

Ровно до пяти поисковых запросов: `Mac mini M1`, `Mac mini M2`, `Mac mini M3`, `Mac mini M4`, `Mac mini M5`. География — вся Россия, первая страница каждого запроса. Между обращениями минимум 11 секунд. Открытия карточек, переходов на следующие страницы, повторов запросов и автоматического продолжения нет. Это ограниченный первичный просмотр, не полный обзор рынка.

Процессор берётся только из текста объявления, никогда из запроса. M3/M5 и другие обозначения показываются лишь при наличии в объявлении, как слова продавца: парсер не утверждает, что Apple выпустила такую конфигурацию. Перед покупкой отдельно проверяются точная модель, серийный номер, процессор и Activation Lock/MDM.

## Фильтры и результат

- Другие устройства Apple, Intel, выкуп, услуги, аренда и отдельные комплектующие исключаются.
- Неясная модель, несколько процессоров, противоречия между названием и характеристиками, неисправность/блокировка, обрезанный текст и расходящиеся варианты одной карточки направляются на ручную проверку.
- Комплект Mac mini с клавиатурой/мышью не отсекается как отдельный аксессуар.
- Все безопасные ссылки сохраняются, включая исключённые объявления, вместе с ценой, городом и причиной. Дубли объединяются по проверенному ID Авито с сохранением запросов-источников.
- Результат виден в Summary запуска. Отдельный artifact `visi-mac-mini-<run_id>` содержит `README.md`, `ads.csv`, `report.json`, `checkpoint.json` и обезличенные аудиты API. Поля продавца, телефон, точный адрес, координаты и API-ключ не сохраняются.

Перед каждым обращением пишется резервирование в checkpoint. При ошибке API/HTTP, тайм-ауте, неверной схеме/источнике/URL или непонятной квоте работа останавливается и сохраняет полученные данные. Неопределённый исход не повторяется. Коды 502/503 также останавливают запуск; число попыток не выдаётся за подтверждённое списание квоты. Перезапуск существующего GitHub run запрещён. Новый ручной запуск создаёт новый отчёт, но не продолжает предыдущий.

## Проверка без API

`python3 -m unittest discover -s tests -v`

Источники контракта: [VISI](https://visi.su/), [официальная документация API](https://api.visi.su/api/v1/docs), проверены 3 ноября 2026 года. Перед первым запуском необходимо подтвердить действующий API-тариф и доступную квоту.
